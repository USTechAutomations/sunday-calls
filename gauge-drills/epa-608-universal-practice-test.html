EPA 608 Universal practice test: studying all four parts

Universal is the Section 608 certification for people who want to work across all the equipment types. We only say what EPA's own pages say. If your testing program builds its test differently, follow your testing program.

What the rule says about the Universal test

Each test must include 25 questions drawn from Group 1 and 25 questions drawn from each relevant technical group.

The federal rule says: "Each test must include 25 questions drawn from Group 1 and 25 questions drawn from each relevant technical Group."

Read it on the official source

A Universal test has 100 questions.

The federal rule says: "Tests for Universal technicians will include 100 questions (25 from Group 1 and 25 from each relevant technical Group)."

Read it on the official source

That adds up to Core plus each of the three equipment groups. Check with your testing program for exactly how your Universal test is put together.

Rules that only apply to Universal

Some ways of taking a test do not count toward Universal. Read these before you book.

For Universal certification the Core test must be a proctored exam.

EPA's page says: "The core test must be taken as a proctored exam in order to attain Universal Certification."

Read it on the official source

Mail-in format Type I tests cannot be used toward a Universal certification.

The federal rule says: "Mail-in format Type I tests cannot be used toward a Universal certification."

Read it on the official source

Open-book or closed-book? Two official pages, two answers

EPA's certification page mentions Core tests taken open-book. The federal rule's appendix says the closed-book test is the one with a set passing score, and it names Universal. The two pages do not line up, so we quote both.

A Core test taken open-book cannot count toward Universal certification.

EPA's page says: "Core tests taken as an open book exam cannot be used to get your Universal Certification."

Read it on the official source

The passing score for the closed-book Type I, II, III and Universal tests is 70 percent.

The federal rule says: "The passing score for the closed-book Type I, Type II, Type III and Universal certification test is 70 percent."

Read it on the official source

Our advice: prepare as if the test will be closed-book and proctored, and ask your testing program which format you will get.

A study plan across all four parts

  1. Start with Core. It is the base for everything else, and you sit it whichever equipment you choose.
  2. Move to Type 1, small appliances.
  3. Then Type 2, high-pressure equipment. Give it the most time, because the leak repair rules are detailed.
  4. Then Type 3, low-pressure equipment. Compare it with Type 2 on vacuum and pressure, because they get mixed up.
  5. Finish with mixed sets that pull from all four parts, closed-book, and read every explanation.

What each part covers

EPA describes Type I certification as the one for servicing small appliances.

EPA's page says: "For servicing small appliances (Type I)."

Read it on the official source

The page describes Type II as for servicing or disposing of high- or very high-pressure appliances, except small appliances and motor-vehicle air conditioners.

EPA's page says: "For servicing or disposing of high- or very high-pressure appliances, except small appliances and MVACs (Type II)."

Read it on the official source

EPA describes Type III as the certification for servicing or disposing of low-pressure appliances.

EPA's page says: "For servicing or disposing of low-pressure appliances (Type III)."

Read it on the official source
